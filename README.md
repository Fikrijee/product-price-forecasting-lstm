# Product Price Forecasting with LSTM

This repository contains an LSTM notebook for exploring daily product-price forecasting.

## Dataset

`price_data_clean.csv` is a deterministic synthetic dataset generated by `generate_synthetic_dataset.py`. It contains four example products over 180 days. These rows are simulated for demonstration and notebook testing; they are not real sales, inventory, or competitor-price observations and should not be used for business decisions.

Run the generator from this folder to recreate the CSV:

```bash
python generate_synthetic_dataset.py
```

The notebook expects `price_data_clean.csv` in the same folder. Its columns include the date and product identifier, own and competitor prices, discount and stock features, encoded demand and season, promotion flag, and rolling price statistics.
